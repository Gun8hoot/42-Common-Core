<div align="center">
    <h1>Push_Swap</h1>
</div>

<div align="center">
    <h2>DESCRIPTION :</h2>
</div>

This program take a list of integer number in arguments and sort it using two stack. He can take number from two different way:
1. The first way is to give him a string with the number to sort on it.
2. The second way is to give the number on many arguments as needed.

<div align="center">
    <h2>INSTALLATION :</h2>
</div>

1. Compile the project using make
```sh
make
```
2. Launch the game with the unsorted list
```sh
./push_swap "45 65 12 0 4 89"
# OR
./push_swap 45 65 12 0 4 89
```
