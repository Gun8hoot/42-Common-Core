<div align="center">
    <h2>DESCRIPTION :</h2>
</div>

On this project ive created a simple 2D game using the 42 internal graphics library called minilibx. On this game you cannot do anything else than collect the different DNA who are on the map and go into the portal when you have done

Five action is available:
- Going up using w or ↑
- Going right using d or →
- Going down using s or ↓
- Going left using a or ←
- Quitting the game using ESC or the cross at the top of the window

<div align="center">
    <h2>INSTALLATION :</h2>
</div>

1. Compile the project using make
```sh
make
```
2. Launch the game 
```sh
./so_long filename.ber
```
