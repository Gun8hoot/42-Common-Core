<div align="center">
    <h2>DESCRIPTION :</h2>
</div>

This project is also usefull for most of our next C projects of the common core. On this project, we have recreated the `printf` function from the libc. This function is used to write complex formated (that why he have an f at the end) string on the terminal.

<div align="center">
    <h2>INSTALLATION : </h2>
</div>

- Compile the library
```sh
make
# OR
make bonus
```
- Remove every object files
```sh
make clean
```
- Remove every object files and the compiled library
```sh
make fclean
```

<div align="center">
    <h2>FORMATING :</h2>
</div>

| Formating | Purpose |
| --------- | ------- |
| %c        | Print a character on the terminal |
| %s        | Print a string on the terminal |
| %p        | Print an address in hexadecimal on the terminal |
| %d        | Print an decimal (base 10) number on the terminal |
| %i        | Print an integer on the terminal |
| %u        | Print an unsigned decimal (base 10) on the terminal |
| %x        | Print a number in hexadecimal (base 16) lowercase on the terminal |
| %X        | Print a number in hexadecimal (base 16) uppercase on the terminal |
| %%        | Print a percent sign on the terminal |
